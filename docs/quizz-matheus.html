Def. 23 O que é Função?

Uma função f: A → B associa a cada x ∈ A um único y ∈ B.
Toda função é relação, mas nem toda relação é função — a unicidade do y é o que distingue.

🗂️ Domínio · Contradomínio · Imagem

Domínio D(f) = A → valores de entrada (x)
Contradomínio CD(f) = B → todos os possíveis valores de saída
Imagem Im(f) ⊆ B → somente os y realmente atingidos por f(x)

⚠️ Im(f) sempre está contida no CD(f), mas pode ser menor!

📐 Domínios Especiais (Lista UNIFOR — Q.5)

f(x) = 3x − x³: domínio = ℝ (polinômio)
f(x) = 5/(x²−9): x ≠ ±3 (denominador ≠ 0)
f(x) = (x²−3x+2)/(x³+2x²−24x): x ≠ 0, 4, −6
f(x) = √(x+5): x ≥ −5 → domínio [−5, +∞)
f(x) = √(x²−8x+12): x²−8x+12 ≥ 0 → x ≠ 2

🔢 Calcular f(x) — Q.2: f(x) = x²−4x+2

f(5) = 25 − 20 + 2 = 7
f(−3) = 9 + 12 + 2 = 23
f(a) = a² − 4a + 2
f(a+b) = (a+b)² − 4(a+b) + 2

🔁 Função Par vs Ímpar

Par: f(−x) = f(x) → simétrico ao eixo y  |  Ex: f(x) = x²
Ímpar: f(−x) = −f(x) → simétrico à origem  |  Ex: f(x) = x³

🏗️ Aplicação — Q.8: Cercamento (A = x(100−2x))

Perímetro = 2x + y = 100 → y = 100 − 2x
Área A(x) = x · y = x(100−2x) = 100x − 2x²
Máximo em x = 25 → A(25) = 1250 m²

🔗 Funções Compostas — Q.4

Dadas f(x) = 1/x² e g(x) = 4−x²:
f(a)·g(b) = (1/a²)·(4−b²)
f(g(a)) = f(4−a²) = 1/(4−a²)²
g(f(b)) = g(1/b²) = 4 − (1/b²)² = 4 − 1/b⁴

📊 Tipos de Gráfico

f(x) = c (constante) → reta horizontal
f(x) = ax+b (1º grau) → reta inclinada
f(x) = ax²+bx+c (2º grau) → parábola (a>0: ∪ / a<0: ∩)
f(x) = x³ → cúbica (S-shape)
f(x) = |x| → V com vértice na origem
